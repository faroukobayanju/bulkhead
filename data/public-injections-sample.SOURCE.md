# public-injections-sample.jsonl

The first 100 rows labeled as injections (`label` 1), in row order, from the `train` split of [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections) at revision `4f61ecb038e9c3fb77e21034b22511b523772cdd`. Downloaded 2026-11-05.

License: Apache-2.0, from deepset. The text is unchanged. `id` is `deepset-train-<row index>`.

These are general prompt injections, and some are in German. Most do not ask for a payout, so the block rate on this file measures how the arena firewall treats outside attacks. It is not a payout benchmark. The strings are test samples to rate, not instructions.
